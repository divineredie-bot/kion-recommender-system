# KION Recommender System

## Описание проекта

Проект посвящён разработке и исследованию рекомендательной системы для контента онлайн-кинотеатра KION. Цель — построить модель, оценивающую вероятность положительного взаимодействия пользователя с фильмом, сравнить подходы и исследовать влияние признаков на качество рекомендаций.

## Данные

Используется датасет взаимодействий пользователей с контентом KION.

Источник данных: [KION_DATASET](https://github.com/irsafilo/KION_DATASET).

Основные поля:
- `user_id` — идентификатор пользователя;
- `item_id` — идентификатор фильма;
- `last_watch_dt` — дата взаимодействия;
- `total_dur` — продолжительность просмотра;
- `watched_pct` — процент просмотренного контента.

Целевая переменная определяется следующим образом: взаимодействие считается положительным, если `watched_pct >= 50`.

Продолжительность просмотра и процент просмотра не используются в качестве признаков модели, чтобы избежать утечки целевой информации.

## Подготовка данных

Данные сортируются по времени и разделяются на историческую часть, обучающую выборку и тестовую выборку.

Используются агрегированные признаки:
- количество взаимодействий пользователя;
- доля положительных взаимодействий пользователя;
- количество взаимодействий с фильмом;
- доля положительных взаимодействий с фильмом.

Статистики для базовых признаков рассчитываются по историческим данным.

## Модели

### Константный baseline

Используется для оценки качества относительно простого прогноза.

### HistGradientBoostingClassifier

Основная модель градиентного бустинга.

Параметры:
- `max_iter=100`;
- `max_leaf_nodes=15`;
- `learning_rate=0.1`;
- `random_state=42`.

### Logistic Regression

Логистическая регрессия используется как дополнительная модель для сравнения.

## Результаты классификации

| Модель | ROC-AUC | LogLoss |
|---|---:|---:|
| Константный baseline | 0.5000 | 0.6613 |
| Logistic Regression | 0.6555 | 0.6244 |
| HistGradientBoostingClassifier | 0.6676 | 0.6182 |

HistGradientBoosting показал лучший ROC-AUC и LogLoss среди этих моделей.

## Эксперимент с временными признаками

Проверено использование агрегированной статистики за последние 7, 30 и 60 дней исторического периода.

| Вариант | ROC-AUC | LogLoss |
|---|---:|---:|
| Базовые признаки | 0.667646 | 0.618229 |
| Временные признаки | 0.668534 | 0.618664 |

Добавление временных признаков немного повысило ROC-AUC, но ухудшило LogLoss. Поэтому однозначного улучшения качества по обеим метрикам не обнаружено.

Важно: временные статистики рассчитываются относительно общего конца исторического периода. Это эксперимент с фиксированным историческим срезом, а не полноценное обновление признаков для каждого момента времени.

## Оценка ранжирования

Для оценки ранжирования сравнивались модель, ранжирование по популярности и случайное ранжирование на одинаковых наборах кандидатов.

| Метод | NDCG@10 | Recall@10 |
|---|---:|---:|
| HistGradientBoosting | 0.0593 | 0.0774 |
| Популярность | 0.0087 | 0.0070 |
| Случайное ранжирование | 0.0608 | 0.0933 |

В данном эксперименте модель превзошла ранжирование по популярности, но немного уступила случайному ранжированию. Поэтому результаты не подтверждают преимущество модели над всеми рассмотренными методами.

Оценка проводилась на выборке с ограниченным набором кандидатов, включающим тестовые взаимодействия и случайно выбранные фильмы из исторического каталога. Это приближённый эксперимент, а не оценка по полному каталогу.

## Холодный старт

В тестовой выборке обнаружено 219 483 взаимодействия новых пользователей — 68,82% всех тестовых взаимодействий.

| Группа | Взаимодействий | ROC-AUC | LogLoss модели |
|---|---:|---:|---:|
| Все пользователи | 318 904 | 0.6676 | 0.6182 |
| Знакомые пользователи | 99 421 | 0.6726 | 0.6342 |
| Новые пользователи | 219 483 | 0.6645 | 0.6110 |

Качество классификации на новых пользователях ниже. Это показывает ограничение подхода, основанного на исторических агрегатах: при отсутствии истории пользователя возможности персонализации уменьшаются.

## Выводы

1. Агрегированные признаки пользователей и фильмов позволяют получить качество классификации выше константного baseline.
2. HistGradientBoosting показал лучший результат среди рассмотренных классификационных моделей.
3. Добавление временных признаков дало неоднозначный эффект.
4. В эксперименте ранжирования модель превзошла популярностный baseline, но не случайный.
5. Большая доля взаимодействий новых пользователей делает холодный старт существенным ограничением.
6. Для дальнейшего улучшения можно исследовать динамические признаки, более корректную генерацию кандидатов и модели, учитывающие последовательность взаимодействий.

## Исследовательская идея и вычислительные затраты

### Исследовательская гипотеза

Проверена гипотеза о том, что статистики взаимодействий за разные временные окна (7, 30 и 60 дней) могут улучшить качество модели по сравнению с базовыми агрегированными признаками пользователей и фильмов.

### Результат эксперимента

Расширение признаков увеличило ROC-AUC с 0.667646 до 0.668534, однако LogLoss ухудшился с 0.618229 до 0.618664. Следовательно, улучшение неоднозначно: расширенный набор признаков не продемонстрировал преимущества по обеим метрикам.

### Вычислительная сложность и масштабирование

Основные затраты связаны с группировкой взаимодействий по пользователям и фильмам, построением агрегированных признаков и обучением градиентного бустинга. Агрегирование позволяет повторно использовать рассчитанную статистику при подготовке признаков для большого числа строк.

При увеличении датасета потребуется учитывать объём памяти при хранении таблиц взаимодействий и агрегатов. Для дальнейшего развития можно исследовать инкрементальное обновление статистик и сравнить время обучения и инференса разных моделей.

### Ограничения исследования

- Временные признаки рассчитаны по фиксированному историческому периоду, а не обновляются перед каждым отдельным взаимодействием.
- В эксперименте ранжирования случайный baseline немного превзошёл обученную модель.
- Для более надёжных выводов потребуется оценка на дополнительных временных срезах и более реалистичном наборе кандидатов.

Таким образом, проект демонстрирует полный базовый экспериментальный цикл: подготовку данных, построение признаков, сравнение моделей, оценку ранжирования и анализ ограничений.
